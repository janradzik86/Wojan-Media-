# WoJan Media Studio

Autonomiczne, wieloplatformowe (Windows 11 + Android) studio multimedialne łączące możliwości edytora audio (klasa *Mstudio*) i kreatora wideo/teledysków (klasa *FotoPlay*) – z lokalnym silnikiem FFmpeg, automatycznymi teledyskami zsynchronizowanymi z rytmem, wizualizatorami, lyric video/karaoke, synchronizacją projektów przez Dysk Google i Social Publisherem. Bez reklam, telemetrii, znaków wodnych i abonamentu.

* Kod: `source/wojan_media_studio` (Flutter) – silnik w `lib/engine`, testy w `test/engine` (prawdziwy FFmpeg).
* Dokumentacja: `docs/` – zacznij od `PROJECT_STATUS.md`, `FEATURE_PARITY_MATRIX.md`, `INSTALLATION_PL.md`, `USER_MANUAL_PL.md`.
* Budowanie: `docs/BUILD_INSTRUCTIONS.md`, CI: `.github/workflows/build.yml`.
